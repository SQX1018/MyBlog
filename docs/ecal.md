# 电磁量能器页面维护

这是现有博客的静态功能页，沿用 AstroPaper 的页头、页脚、字体和蓝色深浅主题。产品约束见 `PRODUCT.md`；不引入后端、外部服务或新的全站视觉规范。

## 入口与文件分工

路由为 `/MyBlog/ecal/`，首页探测器图作为可键盘访问的入口，不显示额外的文字链接。页面中的“了解 VLAST-P”仍连接原有文章。Astro 的 `base` 在 `astro.config.ts` 中为 `/MyBlog`；页面链接和图片使用 `getAssetPath()`，避免重复拼接前缀。

| 文件 | 维护内容 |
| --- | --- |
| `src/pages/index.astro` | 首页探测器入口 |
| `src/pages/ecal.astro` | 页面标题、静态读出说明、报告配图和部件说明 |
| `src/data/ecal.ts` | `ECAL` 尺寸与行列、晶体编号、`parts` 部件说明、`steps` 四步文案 |
| `src/components/EcalExplorer.astro` | 控件、静态 SVG、可访问名称、状态区域与 Astro 挂载生命周期 |
| `src/scripts/ecal-viewer.ts` | Three.js 实体模型、材质、拾取、视角、拆解、演示、资源释放和回退 |
| `src/styles/ecal.css` | 本页布局、控件、手机断点和减少动态效果规则 |
| `src/styles/theme.css` / `src/styles/observatory.css` | 原有全站主题令牌与视觉层，继续作为样式依据 |

## 模型尺寸与简化范围

模型空间以毫米（mm）计，`ECAL` 为 5 行 × 5 列，单根 CsI(Tl) 晶体为 60 × 60 × 150 mm。代码中 `width` 对应 X、`height` 对应 Y（150 mm 长轴）、`depth` 对应 Z；`BoxGeometry` 参数顺序为宽、高、深。晶体从 Y=0 延伸至 Y=150，APD、FAM 位于底部，FEE 位于侧面。阵列标称尺寸为 300 × 300 × 150 mm，不含包装及支撑。

编号 C01–C25 按行生成。修改尺寸或阵列时，除 `ECAL` 外，还需检查三维模型和静态 SVG 中的居中偏移、位置、顶面饰片、支撑及标签坐标，以及页面固定尺寸文案；当前实现针对已确认的 5×5 方案，并非任意阵列生成器。

晶体采用实体表达；APD 封装与数量、电路板形状与走线、紧固件及工程公差经过简化。拆解位移仅便于观察。演示的粒子分支、光点数量、传播路径与时间为定性示意，不代表仿真结果或测量数据。

## 交互、主题与回退

- 默认进入“结构探索”。拖动旋转，滚轮或双指缩放；工具栏提供旋转、缩放和复位。画布聚焦后支持方向键、加减键和 Home。拆解滑块为 0–100%，部件按钮、单晶体网格及画布拾取同步说明和选中状态。
- “原理演示”提供能量沉积、晶体闪烁、光电转换、电子学读出四步，支持直接选步、上一步、下一步和从头开始。切换模式不会自动播放；访问者点击播放后开始，支持暂停、继续和结束后重播。每步由 `STEP_DURATION = 3200` 控制，总时长由步骤数计算。复位会停止播放、合拢结构、恢复视角和初始选择。
- `ecal.css` 使用既有主题变量；部件材质色用于识别结构，未新增全站调色板。脚本监听根元素的 `data-theme`，更新选中高亮等材质。宽度小于 768px 时改为上下布局，模型舞台高 390px；操作目标至少 44px。
- `prefers-reduced-motion: reduce` 下关闭按钮过渡并禁用自动播放，仍保留手动分步；运行中偏好变化也会停止播放。模型静止时不持续渲染，页面隐藏或舞台离开视口时暂停帧调度；像素比上限为 1.5。
- Astro 页面切换、`pagehide` 时调用清理函数，撤销事件、观察器、动画帧并释放 Three.js 几何体、材质、控制器和渲染器；`astro:page-load` 及往返缓存恢复时重新挂载，避免重复实例。
- JavaScript 关闭、WebGL 初始化失败或上下文丢失时保留静态 SVG、报告图、四步文字与“部件说明”；不可用的交互控件保持禁用。上下文丢失后刷新可重新尝试加载。

## 本地预览与验证

在项目根目录的 PowerShell 中运行，先为当前进程关闭 Astro 遥测：

```powershell
$env:ASTRO_TELEMETRY_DISABLED = '1'
npm.cmd run dev -- --host 127.0.0.1
```

开发预览为 `http://127.0.0.1:4321/MyBlog/ecal/`。完成修改后构建：

```powershell
$env:ASTRO_TELEMETRY_DISABLED = '1'
npm.cmd run build
```

构建包含类型检查、静态输出和 `scripts/build-search.mjs` 的 Pagefind 索引生成。需要检查构建产物时运行 `npm.cmd run preview -- --host 127.0.0.1`，按终端端口访问同一路径。

被 Git 忽略的 `work/ecal-review/` 保存截图和 `validation.json`；验证脚本位于同样被忽略的 `work/`。已有验证涵盖入口、尺寸、旋转缩放、拆解与选择、四步播放、主题、减少动态效果、Astro 往返挂载、触屏及静态回退。修改后复查桌面深浅主题、平板、390×844 手机首页与功能页，并运行相应交互检查；历史记录不能代替本次验证。上传和部署依当前用户请求执行。
