# 电磁量能器页面维护

这是现有博客的静态功能页，沿用 AstroPaper 的页头、页脚、字体和蓝色深浅主题。产品约束见 `PRODUCT.md`；不引入后端、外部服务或新的全站视觉规范。

## 入口与文件分工

路由为 `/MyBlog/ecal/`，首页探测器图作为可键盘访问的入口，不显示额外的文字链接。页面中的“了解 VLAST-P”仍连接原有文章。Astro 的 `base` 在 `astro.config.ts` 中为 `/MyBlog`；页面链接和图片使用 `getAssetPath()`，避免重复拼接前缀。

| 文件 | 维护内容 |
| --- | --- |
| `src/pages/index.astro` | 首页探测器入口 |
| `src/pages/ecal.astro` | 页面标题、静态读出说明、报告配图和部件说明 |
| `src/data/ecal.ts` | `ECAL` 尺寸与行列、晶体编号、`parts` / `steps` 的摘要和详解 |
| `src/components/EcalExplorer.astro` | 控件、静态 SVG、可访问名称、状态区域与 Astro 挂载生命周期 |
| `src/scripts/ecal-viewer.ts` | Three.js 实体模型、材质、拾取、视角、拆解、演示、资源释放和回退 |
| `src/components/EcalReferenceViewer.astro` / `src/scripts/ecal-images.ts` | 参考图原生 `dialog`、缩放拖动和挂载清理 |
| `src/styles/ecal.css` | 本页布局、控件、手机断点和减少动态效果规则 |
| `src/styles/theme.css` / `src/styles/observatory.css` | 原有全站主题令牌与视觉层，继续作为样式依据 |

## 模型尺寸与简化范围

模型空间以毫米（mm）计，`ECAL` 为 5 行 × 5 列，单根 CsI(Tl) 晶体为 60 × 60 × 150 mm。代码中 `width` 对应 X、`height` 对应 Y（150 mm 长轴）、`depth` 对应 Z；几何体参数顺序为宽、高、深。晶体从 Y=0 延伸至 Y=150，APD、FAM 位于底部，FEE 位于侧面。阵列标称尺寸为 300 × 300 × 150 mm，不含包装及支撑。

编号 C01–C25 按行生成。修改尺寸或阵列时，除 `ECAL` 外，还需检查三维模型和静态 SVG 中的居中偏移、位置、顶面饰片、支撑及标签坐标，以及页面固定尺寸文案；当前实现针对已确认的 5×5 方案，并非任意阵列生成器。

晶体采用 `RoundedBoxGeometry` 实体表达，轻微倒角为 0.65 mm；晶体、电子学和金属支撑通过粗糙度与金属度区分。接触阴影由本地 Canvas 径向渐变生成，不依赖外部纹理或额外阴影贴图渲染。框架单独放在 `supportFrame` 中，与底座同属支撑部件，但拆解时沿不同方向移动。

APD 封装与数量、电路板形状与走线、紧固件及工程公差经过简化。倒角、阴影和拆解位移便于辨认结构，不作为工程参数。演示的粒子分支、光点数量、传播路径与时间为定性示意，不代表仿真结果或测量数据。

## 交互、主题与回退

- 顶部切换“结构探索 / 原理演示”，并提供整体视角、底部读出、单根晶体三个预设；选择预设会回到结构模式。默认是整体装配。拖动旋转，滚轮或双指缩放；工具栏提供旋转、缩放和复位。画布聚焦后支持方向键、加减键和 Home。
- “分层拆解”为 0–100%，主要沿 Y 轴拉开层次；FEE 另有向侧面的位移。默认保持晶体横向间距，单晶体选择区内的“拉开晶体间距”独立增加晶体节距，APD/FAM 仍保持原阵列位置。调整 `applyExplosion()` 时同步检查框架、底座、标签、接触阴影和自动取景。
- 部件按钮、单晶体网格及画布拾取同步近旁摘要、详解、选中轮廓和带引线标签。“查看此层”展开结构并调整视角；单根晶体预设或选中单晶体后的“查看此层”，仅保留该晶体及对应 APD/FAM，便于观察读出关系。整体预设和复位恢复装配视图。
- “原理演示”提供能量沉积、晶体闪烁、光电转换、电子学读出四步，支持直接选步、上一步、下一步和从头开始。切换模式不会自动播放；访问者点击播放后开始，支持暂停、继续和结束后重播。每步由 `STEP_DURATION = 3200` 控制，总时长由步骤数计算。复位会停止播放、合拢结构、恢复视角和初始选择。
- `ecal.css` 使用既有主题变量；部件材质色用于识别结构。脚本监听根元素的 `data-theme`，更新高亮与轮廓等材质。模型下方保留选择/步骤摘要，演示中提供闪烁光与电信号图例；“部件详解与尺寸”在桌面默认展开、手机默认折叠，断点变化时同步状态。
- 宽度小于 768px 时改为上下布局，模型、工具栏和摘要使用 sticky，舞台高度为 `clamp(235px, 34svh, 290px)`；短屏（高度不超过 600px）取消 sticky，避免遮挡操作区。按钮和主要操作行至少 44px。尺寸规则集中在 `ecal.css`，修改时复查滚动中的可读面积。
- 预设视角通常以 360 ms 过渡；`prefers-reduced-motion: reduce` 下直接切换视角、关闭按钮过渡并禁用自动播放，仍保留手动分步；运行中偏好变化也会停止播放并结束视角过渡。模型静止时不持续渲染，页面隐藏或舞台离开视口时暂停帧调度；像素比上限为 1.5。
- Astro 页面切换、`pagehide` 时调用清理函数，撤销事件、观察器、动画帧并释放 Three.js 几何体、材质、生成的纹理、控制器和渲染器；`astro:page-load` 及往返缓存恢复时重新挂载，避免重复实例。
- JavaScript 关闭、WebGL 初始化失败或上下文丢失时保留静态 SVG、报告图、四步文字与“部件说明”；不可用的交互控件保持禁用。上下文丢失后刷新可重新尝试加载。

## 报告配图

图片保存在 `public/images/ecal/`：`assembly-reference.png` 为装配参考，`readout-reference.png` 为读出框图；页面通过 `getAssetPath("images/ecal/…")` 引用。用户已授权使用提供报告中的图文，并明确要求展示时不标来源页码；后续图片、图注、替代文字及界面说明继续遵守这一决定。

装配参考图展示 6×6 初步方案，交互模型为 5×5 最小化方案；保留页面对两者的说明，避免将参考图误称为模型的精确工程图。

每张缩略图都是指向真实图片文件的普通链接；无 JavaScript 时直接打开图片，修饰键点击仍保留浏览器链接行为。脚本拦截普通点击后使用原生 `dialog.showModal()`，支持相对适应窗口大小的 1–5 倍缩放、拖动、双指缩放、双击切换和 Ctrl+滚轮；“适应窗口”恢复 100%。Escape、关闭按钮或点击遮罩关闭，焦点返回触发链接，并恢复页面滚动。SPA 切换及 `pagehide` 时关闭弹窗、恢复滚动、清理事件/指针/观察器；新增配图继续保留真实 `href`、`data-reference-image`、图题和替代文字。

## 本地预览与验证

在项目根目录的 PowerShell 中运行，先为当前进程关闭 Astro 遥测：

```powershell
$env:ASTRO_TELEMETRY_DISABLED = '1'
npm.cmd run dev -- --host 127.0.0.1
```

开发预览为 `http://127.0.0.1:4321/MyBlog/ecal/`。完成修改后构建：

```powershell
$env:ASTRO_TELEMETRY_DISABLED = '1'
npm.cmd run build
```

构建包含类型检查、静态输出和 `scripts/build-search.mjs` 的 Pagefind 索引生成。需要检查构建产物时运行 `npm.cmd run preview -- --host 127.0.0.1`，按终端端口访问同一路径。
